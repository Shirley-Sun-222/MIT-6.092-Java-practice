# MIT-6.092-Java-practice

Practice Java with "MIT 6.092: Introduction To Programming In Java"

## Overview

This repository contains Java programming exercises and examples for MIT 6.092: Introduction to Programming in Java. The course covers fundamental programming concepts including variables, methods, control structures, arrays, and object-oriented programming.

## Getting Started

### Prerequisites
- Java Development Kit (JDK) 8 or higher
- A text editor or IDE (Eclipse, IntelliJ IDEA, VS Code, etc.)

### Project Structure
```
MIT-6.092-Java-practice/
├── src/                    # Source code files
│   ├── HelloWorld.java     # Simple hello world program
│   └── JavaBasics.java     # Basic Java concepts demonstration
└── README.md              # This file
```

## Running the Programs

### Compile and Run Hello World
```bash
# Compile
javac src/HelloWorld.java

# Run
java -cp src HelloWorld
```

### Compile and Run Java Basics Demo
```bash
# Compile
javac src/JavaBasics.java

# Run
java -cp src JavaBasics
```

## What's Covered

The `JavaBasics.java` program demonstrates:
- **Variables and Data Types**: int, double, boolean, char, String
- **Methods**: Method definition, parameters, and return values
- **Control Structures**: if/else statements and for loops
- **Arrays**: Array creation, initialization, and iteration

## Course Topics

MIT 6.092 typically covers:
1. Introduction to Java and programming
2. Variables and data types
3. Methods and parameters
4. Conditional statements
5. Loops and iteration
6. Arrays
7. Object-oriented programming concepts
8. Classes and objects
9. Inheritance and polymorphism
